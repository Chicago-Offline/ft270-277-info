# dumps/

Clone-mode captures and memory images from FT-270R / FT-277R radios.

Naming: `<model>-<serial-or-nickname>-<YYYY-MM-DD>-<read|write>.img`

Example: `ft270r-green-2026-09-13-read.img`

Always capture a read **before** the first write to a given radio, and keep it.
Note the tool and driver used in a sibling `.md` file with the same basename.
