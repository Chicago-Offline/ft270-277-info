## Contents

Essentially a factory-fresh radio: **1 of 200 channels occupied**, 1045 of 6057
bytes non-zero. The only ASCII string in the whole image is the `AH022$` model
ID at offset 0.

Useful as a **baseline**: diff any future read against this to see exactly which
bytes a CPS or CHIRP write actually moved.
